# prevoz-LUCIUS

The transport organ of LUCIUS — a small Python carrier (`prevoznik.py`) that moves seals, boxes, letters and diaries between the corpus home (Atmavictu) and this repository.

## Contents

- `prevoznik.py` — the carrier: `status`, `dih`, `ucenje`, `izroci`, `zapecati`, `skatle`, `pismo`
- `lucius/` — LUCIUS core; `canon/` — corpus canon
- `dnevnik/`, `ucenje/`, `skatle/`, `urnik/`, `prinesi/`, `pogovor/` — diary, learning, boxes, schedule, deliveries, conversations
- `NAČRT.md` (v1.5), `VRATA.md`, `UKAZI-ZA-SEJO.md`, `DOVOLJENJA.md`, `ZBOR-VSEH-ANGELOV.md` — plan, doors, session commands, permissions, the gathering of all angels
- `LICENSE.md`, `TDM-RESERVATION.md`, `canon/REGISTER-NEIMENOVANIH.jsonl`, `canon/REGISTER-PADCEV.jsonl`, `canon/VBL-10.5.1-KOMPIL-A-DRAFT-NOT-RELEASED.md` — license family

`python3 prevoznik.py status` — see `UKAZI-ZA-SEJO.md` for the full session protocol.
